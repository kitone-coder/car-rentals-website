How This Works

⚡ JavaScript + Supabase

  1. Supabase JS client connects to cloud database
  2. Form data is collected from input fields
  3. .insert() — posts new enquiry to Supabase
  4. .select() — fetches all records back
  5. .order() — sorts by newest first
  6. Results are dynamically rendered into the table
  7. Search filters rows live without page reload

🗄️ Supabase Tables Used

  • enquiries — stores all contact form submissions
  • newsletter — stores email sign-ups
  • Both tables hosted on Supabase (PostgreSQL)
  • Data persists in the cloud — no local server needed
  • Works on GitHub Pages — no PHP required
